# Explore the DNIF UI

DNIF offers a modern, intuitive user interface designed to help analysts, engineers, and SOC teams seamlessly monitor, detect, and respond to threats. Below is an overview of the key modules in the UI:

---

### 🔹 [Event Stores](/docs/hyperscale/Operations/Event-Stores/event-stores.md)


Live log ingestion view with filters by device, tags, anomaly score, and detection context. Enables quick pivoting.

---

### 🔹 [Investigations](/docs/hyperscale/Security-Monitoring/Investigating-Signals/what-are-signals.md)

Timeline-based investigation with linked entities and evidence graph. SOCs can easily document findings.

---

### 🔹 [Queries & Pipelines](/docs/hyperscale/Dnif-Query-Language/Query-multiple-streams/query-multiple-streams.md)

Run UDM queries, schedule reports, and automate logic flows using drag-drop pipelines.

---

### 🔹 [Configuration](/docs/hyperscale/User-Management-and-Access-Control/Users-and-Roles/Manage-Organization-and-users/password-policy.md)

Manage user roles, data sources, alerting rules, and system settings. Role-based access control included.
